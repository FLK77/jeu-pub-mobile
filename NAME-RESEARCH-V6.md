# Nom de la V6 : Orvécendre

**Orvécendre** est un nom inventé pour le projet, choisi le 28 octobre 2026. Il évoque l’or de la couronne et la renaissance d’un royaume dans les cendres.

Le nom affiché conserve l’accent ; les fichiers de téléchargement utilisent **Orvecendre** pour faciliter leur ouverture sur tous les appareils.

Une recherche a été tentée sur l’API des dépôts GitHub (`Orvecendre`) et le catalogue Steam (`Orvecendre`). Les deux accès ont été refusés par le proxy réseau avec une réponse HTTP 403 ; ils ne permettent donc pas de conclure à l’absence d’homonyme.

L’absence de tout jeu homonyme et la disponibilité commerciale ou juridique du nom ne sont pas affirmées. Les précédentes recherches sur Cendrune sont conservées dans [NAME-RESEARCH-V5.md](NAME-RESEARCH-V5.md) à titre historique.
