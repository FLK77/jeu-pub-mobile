# Nouveau nom proposé pour la V5 : Cendrune

Vérifications effectuées le **26 octobre 2026**, heure de Paris.

**Cendrune** réunit les cendres du royaume détruit et les runes découvertes en exploration. Huit lettres, sans accent, prononcé « san-drune » : le nom accompagne la reconstruction et les surprises de la V5. Il remplace Courvane pour cette version.

- Nom affiché : **Cendrune**.
- Identifiant du projet : `cendrune`.
- Archive PC conseillée : `Cendrune-PC-V5.zip`.
- Alternatives vérifiées : **Eldorive** et **Brivalis**.

## Conclusion et formulation de publication

**Aucun dépôt GitHub public n’a été trouvé sous le terme « Cendrune » lors du contrôle accessible.** Le nom est retenu comme nouvelle proposition pour le projet. La disponibilité dans les catalogues de jeux n’a pas pu être confirmée et aucune exclusivité mondiale ni disponibilité de marque n’est affirmée.

Formulation fidèle : « La V5 s’appelle désormais Cendrune. Aucun résultat n’a été trouvé dans la recherche GitHub accessible ; la disponibilité dans les catalogues de jeux reste à confirmer. »

La recherche précédente reste documentée dans [NAME-RESEARCH.md](NAME-RESEARCH.md) pour conserver l’historique de Courvane.
